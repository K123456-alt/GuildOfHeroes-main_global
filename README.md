## Ответы на вопросы
1. Почему при yaroslav.TakeDamage(25); не меняется здоровье Артёма и куда попадает 25?
TakeDamage — метод экземпляра, работает с полями того объекта, у которого вызван (слева от точки). yaroslav.TakeDamage(25) меняет yaroslav.Health, а не artem.Health. Артёму метод не вызывали — его здоровье остаётся 120. Аргумент 25 копируется в параметр damage, затем Health -= damage вычисляет 100 - 25 = 75 и записывает в yaroslav.Health.
2. Чем отличаются return; в TakeDamage и return Health > 0; в IsAlive?
return; в void-методе просто немедленно завершает вызов, ничего не возвращая (защитный выход при damage <= 0). return Health > 0; в bool-методе вычисляет выражение и возвращает результат true/false вызывающему коду, затем завершает метод.
3. Как получить строку о герое, не печатая её сразу? Какая строка программы печатает её позже?
Сохранить результат GetInfo() в переменную: string info = yaroslav.GetInfo(); — строка создана, но на экране ничего нет. Печатает её позже строка Console.WriteLine(info);

- Пять методов Hero: ```TakeDamage, Heal, GainExperience, IsAlive, GetInfo.```

- Недопустимый урон: ```yaroslav.TakeDamage(-20)``` — здоровье не изменилось (осталось 75).
- Итог: Ярослав — ```Health 85, Experience 65; Анастасия — Health 60, Experience 0; Артём — Health 0, Experience 0```
## Дополнительные вопросы
1. Что такое метод экземпляра и чем он отличается от поля?
Метод экземпляра — это действие, которое умеет выполнять объект. Он объявлен внутри класса без ```static```
2. Как значение при вызове попадает в параметр?
При вызове yaroslav.TakeDamage(25) число 25 копируется в параметр damage, объявленный в методе
3. Что означает ```void?```
```void``` означает, что метод ничего не возвращает. Он просто выполняет действия и завершается. У ```TakeDamage```, ```Heal```, ```GainExperience``` тип ```void```.
4. Чем отличаются return; и return Health > 0;?
```return;``` просто сразу завершает метод, ничего не возвращая. Используется в void-методах. ```return Health > 0```; вычисляет выражение и возвращает результат true или false в место вызова
5. Какие значения возвращает bool и как сохранить ответ IsAlive()?

```bool``` возвращает только ```true``` или ```false```
6. Почему GetInfo() возвращает строку, а вывод выполняется в Program.cs?

```GetInfo()``` только формирует строку и возвращает её через ```return```
7. Почему один метод изменяет состояние только того героя, у которого вызван?
Метод экземпляра работает с полями того объекта, у которого его вызвали 
8. Как внешний код пока может обойти проверки методов?

Поля объявлены public, поэтому Program.cs может напрямую записать любое значение

## ПР №3. Инкапсуляция собственного класса (10 шаг)
Выбранное правило: поле HoursPlayed не может быть отрицательным и не превышает 10000.
Где проверяется: в конструкторе (начальное значение) и в методе AddHours (после вызова).
Недопустимое действие: AddHours(-3) — HoursPlayed осталось 12; AddHours(20000) — HoursPlayed стало 10000 (граница).
Прямое присваивание game1.HoursPlayed = -5 из Program.cs не компилируется (private set).
